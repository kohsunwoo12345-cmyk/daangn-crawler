# 🥕 Daangn Signage — 디지털 사이니지 프로그램

내 컴퓨터에 **HDMI로 연결한 3개 화면(모니터/TV)** 에 사진·영상을 계속 재생하는 데스크톱 프로그램입니다.
Electron 기반이라 Windows에서 바로 실행할 수 있고, 사진/영상을 끌어다 넣고 버튼으로 재생합니다.

## ✨ 주요 기능

- **3가지 표시 방식**
  - 🔁 **미러링** — 같은 사진/영상을 3개 화면에 동시에 똑같이 재생
  - 🖼️ **비디오월** — 하나의 큰 영상/사진을 3개 화면에 걸쳐 이어서 표시
  - 🔢 **각각(독립)** — 화면마다 서로 다른 재생목록을 따로 재생
- 사진·영상 **재생목록** 구성 (순서 변경 ▲▼, 삭제 ✕)
- 사진별 **표시 시간(초)** 지정, 영상은 끝까지 재생 후 다음으로
- 재생목록 **무한 반복**, 화면 전환 시 **크로스페이드**
- **모니터 자동 감지** 및 화면별 모니터 배정
- 영상 **음소거 / 화면 맞춤(여백·꽉채움·늘려채움)** 옵션
- 재생 중 **이전/다음/일시정지/재개/소리** 실시간 제어
- 🧪 **테스트(창모드)** — 모니터가 1개뿐이어도 작은 창 3개로 미리보기

## 🚀 실행 방법 (Windows)

### 1) Node.js 설치
[https://nodejs.org](https://nodejs.org) 에서 LTS 버전을 설치합니다. (설치 시 기본 옵션 그대로)

### 2) 프로그램 실행
명령 프롬프트(또는 PowerShell)에서:

```bash
cd signage
npm install      # 최초 1회만 (Electron 다운로드)
npm start        # 제어판 실행
```

제어판이 뜨면:
1. **표시 방식**(미러링/비디오월/각각) 선택
2. **화면 개수**와 **모니터 배정** 확인
3. **＋ 사진 / 영상 추가** 로 파일 선택
4. **▶ 재생 시작** 클릭 → 각 모니터에 전체화면으로 재생

> 모니터가 아직 1개뿐이라면 좌측의 **🧪 테스트(창모드)** 를 켜고 재생하면 작은 창 3개로 미리볼 수 있습니다.

전체화면 재생 창을 닫으려면 해당 화면에서 **Esc** 키 (또는 제어판에서 **■ 정지**).
재생 화면에서 **← / →** 키로 이전·다음 이동도 됩니다.

### 3) 설치파일(.exe) 만들기 — 선택
다른 PC에 배포하거나 더블클릭 실행하고 싶다면:

```bash
npm run dist            # 설치형 .exe (NSIS) 생성
npm run dist:portable   # 무설치 portable .exe 생성
```

결과물은 `signage/dist/` 폴더에 생성됩니다.

## 📁 파일 구성

| 파일 | 설명 |
|------|------|
| `main.js` | Electron 메인 프로세스 — 모니터 감지, 화면 창 생성/배치 |
| `preload.js` | 제어판 ↔ 메인 안전 통신 브리지 |
| `control.html` / `control.js` | 제어판 UI 및 로직 |
| `display.html` / `display.js` | 각 화면(전체화면) 재생 엔진 |
| `package.json` | 의존성 및 빌드 설정 |

## 🖥️ 지원 미디어 형식

- **사진**: jpg, jpeg, png, gif, webp, bmp, svg
- **영상**: mp4, webm, ogv, mov, m4v 등 (코덱은 Chromium 지원 범위 — mp4/H.264, webm 권장)

## 💡 참고

- 비디오월은 3대 모니터가 **같은 해상도로 가로로 나란히** 놓였을 때 가장 자연스럽습니다.
- 영상 소리를 켜려면 옵션에서 음소거를 해제하거나 재생 중 **🔊 소리켜기** 를 누르세요.
- 모니터를 새로 연결했다면 **🔄 모니터 다시 감지** 를 누른 뒤 배정을 확인하세요.
