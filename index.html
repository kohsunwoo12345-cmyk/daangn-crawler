재생목록

멀티 모니터 사용법
① 재생목록을 채우고 → ② 연결된 모니터 감지(권한 허용) → ③ 화면 1·2·3을 하나씩 클릭해 엽니다.
중요: 브라우저가 팝업을 막기 때문에 한 번에 여러 창을 못 엽니다. 그래서 버튼을 하나씩 눌러 각 모니터 창을 여세요(팝업이 차단되면 주소창에서 팝업 허용).
각 창은 배정된 모니터로 자동 이동하며, 창을 한 번 클릭하면 전체화면(소리 켜짐)이 됩니다. 같은 PC·브라우저 창끼리 자동 동기화. 해제는 Esc.
재생 대기 중 · 제어 창에서 재생을 누르세요
클릭하면 전체화면 + 소리 켜짐 · Esc 로 해제
